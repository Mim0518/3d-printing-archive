# 3D Printing Archive

Aplicación web para archivar y administrar una colección de impresión 3D: inventario de modelos y piezas, etiquetado, miniaturas, placas y escenas, almacenamiento frío (Google Drive y disco externo), impresoras y materiales, existencias impresas, pedidos y colecciones para venta.

- Backend: Rust (Axum + SQLite).
- Frontend: React + Vite + TypeScript.
- Corre en un mini PC en casa; desde fuera se entra por Tailscale.

Estado: diseño. Ver la [especificación](docs/especificacion.md).
